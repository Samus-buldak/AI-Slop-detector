AI SLOP DETECTOR — ЗАПУСК НА WINDOWS И macOS

1. Распакуй ZIP целиком и открой папку AI-Slop-detector.
2. Установи Python 3.13 с python.org. В установщике Windows оставь включённым
   Python Launcher (py) и добавь Python в PATH.
3. Установи LM Studio с lmstudio.ai. Скачай модель Qwen3 Embedding 0.6B
   (в LM Studio ищи qwen3-embedding-0.6b). Открой вкладку Developer,
   загрузи модель с идентификатором qwen3-embedding-local и включи Local Server
   на порту 1234. Проект обращается к http://127.0.0.1:1234/v1.
   Если нужно задать идентификатор через CLI, выполни lms ls, затем
   lms load MODEL_KEY --identifier qwen3-embedding-local
   Подставь MODEL_KEY из вывода lms ls. Запуск сервера через CLI:
   lms server start --port 1234
   Документация:
   https://lmstudio.ai/docs/cli/local-models/load
   https://lmstudio.ai/docs/cli/serve/server-start
4. Windows — запусти START_WINDOWS.bat.
   macOS — открой Терминал, перейди в распакованную папку и выполни:
   bash START_MAC.command
   При первом запуске установятся зависимости. Для установки нужен интернет.
5. В главном меню выбери 1. Приложенные веса работают по схеме из 4 зон.
   Для проверки примера выбери 3 в меню анализа и введи examples/sample.eml.
   Для своего текста выбери 1 в меню анализа и введи текст одной строкой.
   Для текста с абзацами используй TXT-файл в режиме командной строки.

ВСЕ 21 ЗОНА И СМЫСЛОВАЯ СЕГМЕНТАЦИЯ

1. В главном меню выбери 2. При первом запуске будет создан файл .env.
2. Заполни в нём API_URL, API_KEY и MODEL для chat-провайдера с
   OpenAI-совместимым /chat/completions. API_URL указывается до
   /chat/completions, обычно с /v1. Значения в .env.example — пример для
   провайдера проекта. Для анализа фото укажи модель с поддержкой изображений
   в VISION_MODEL и при необходимости VISION_API_URL и VISION_API_KEY.
3. Подтверди обучение. Оно использует data/dataset.csv и запишет новые
   веса в artifacts/model_hybrid_qwen/. При внешнем chat API части текстов
   будут отправлены настроенному провайдеру, возможен расход квоты.
4. По окончании откроется меню анализа. При следующем запуске выбирай 1.

КОМАНДНАЯ СТРОКА

Сначала выполни установку через запускной файл. Команды выполняются из папки
проекта. В примерах для macOS используется .venv-local/bin/python.
Для Windows в CMD используй .venv-local\Scripts\python.exe.

Проверка подключения к локальным Qwen-эмбеддингам:
  .venv-local/bin/python -m src.api.local_qwen check

Анализ EML с результатом в JSON:
  .venv-local/bin/python -m src.api.local_qwen analyze examples/sample.eml --json

Анализ многострочного TXT:
  .venv-local/bin/python -m src.api.local_qwen text "путь к тексту.txt"

Анализ новой моделью с настроенным chat-провайдером:
  .venv-local/bin/python -m src.api.local_qwen analyze --llm-from-env examples/sample.eml --json

Проверка установки:
  .venv-local/bin/python -m pytest -q

Если появляется ошибка Qwen endpoint, проверь порт 1234 и идентификатор
qwen3-embedding-local в LM Studio. Для запуска с сохранёнными весами на 4 зоны
достаточно локальных Qwen-эмбеддингов. Веса 21-зонной модели создаются обучением
из меню. Пример письма и обучающий CSV уже в архиве.
